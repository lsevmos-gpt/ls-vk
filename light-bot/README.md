# Линия спорта · Свет — Telegram Worker v3

Это безопасный этап настройки бота **без автоматической публикации в социальные сети**.

## Установка

1. В Cloudflare Dashboard -> D1 -> `ls-light-db` -> Console выполните SQL из `migration-v3.sql`. Скрипт создаёт только две новые таблицы и индекс. Старые записи не удаляются.
2. Откройте существующий Worker `shrill-brook-15a0-ls-light-bot` -> Edit code, замените содержимое `worker.js` кодом из файла `worker.js` этой папки и нажмите Deploy.
3. Не изменяйте действующий webhook Telegram, секрет `TELEGRAM_BOT_TOKEN` и binding `DB`.
4. Отправьте боту /start, выберите «Все клубы» -> «Свет есть во всех клубах» -> подтверждение.
5. Проверьте в D1: `SELECT id,name,status FROM clubs;`, а также `SELECT operation_id,scope,new_status,changed_count FROM light_operations ORDER BY created_at DESC LIMIT 10;`.

## Права

«Все клубы» доступно владельцу и только сотрудникам, которым предоставлены права на каждый из трёх клубов. Роли и связи читаются из существующих таблиц `admins` и `admin_clubs`, ID сотрудников не записаны в код.

## Безопасность

- Сохраняется действующий секрет проверки Telegram webhook.
- Запрещён вызов бота из групп.
- SQL-изменения выполняются в одной транзакции D1.batch().
- Повторная доставка callback не изменяет данные ещё раз.
- Общее действие требует дополнительного подтверждения.
- Сторис Instagram и VK не публикуются и в очередь не ставятся.
- Публикация будет подключена отдельным этапом после настройки восьми изображений.

Этот код следует развёртывать вручную в существующий Cloudflare Worker. Ветку GitHub можно использовать для просмотра и копирования кода; публикации в соцсетях она не запускает.
