Медиа: Buffer требует публичный HTTPS URL **самого** файла без авторизации. URL приватного GitHub и обычная ссылка Google Drive не гарантируют такой доступ. Сначала проверяйте реальную ссылку и технический формат. Даже при ответе API OK фактический выход Story может отличаться; receipt означает лишь *accepted/submitted*.
