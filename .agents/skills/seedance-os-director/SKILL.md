# Director lens — Skill OS

Source: https://github.com/Emily2040/seedance-2.0 (Seedance 2.0 Skill OS). This independently authored project-local adaptation is NOT the entire upstream source package.

For EACH prompt establish: intention and viewer outcome, visible opening frame, a single principal action/event and observable end state, blocking and eye line, coherent geography, motivated camera framing/move with beginning and endpoint, physical light source and purposeful sound. For dramatic story beats, define what changes between start and end; for a demonstration, define what action is proven onscreen.

If a reel spans multiple clips, make each standalone generation's end state carry over through clothes, props, person, lighting direction, eyeline and camera side. Do not say "as in the last scene" without the actual continuity anchors.

2.0: use as the primary version-specific directing approach; verify current model/provider limits. 2.5: use only film direction and sequence rules; do not transfer 2.0 @Image1/@Video1 or capability numbers without evidence.

Return precise, filmable instructions and reject visually meaningless camera jargon.
