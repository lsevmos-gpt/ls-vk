# Wan3 Studio for Evmos

Model-specific prompt drafting extension for Wan 3.0 and Wan 3.0 Prime. Developed from official Alibaba Cloud guidance and provider parameter checks. Includes timed shot grammar, multimodal reference discipline, sound design and liquid-physics QA for ads. Complementary to Evmos eight-role review.

The official `wan3-pe.zip` mentioned in Alibaba's documentation is not bundled or installed; this is a locally authored alternative. This GitHub folder does not automatically install the skill on a Windows machine or into a ChatGPT account. For Codex, use the Evmos Wan3 Windows addon to install the full studio profiles and three agent TOMLs.
